# Security policy

OmaTube stores YouTube session cookies locally and runs a native messaging host for the browser extension. Please report vulnerabilities privately rather than in a public issue.

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/vornashev/OmaTube/security/advisories/new). Describe the issue, how to reproduce it and the version affected. Expect a first reply within a week.

## Supported versions

Only the latest release receives fixes.
